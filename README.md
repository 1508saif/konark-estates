# Konark Estates — Exact UI Recreation

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling, alignment, spacing, typography and icons
- `script.js` — enquiry modal, explore button and basic interactions
- `assets/logo.png` — cropped visual asset from the supplied reference
- `assets/building.png` — cropped building visual from the supplied reference

## Run
Open `index.html` directly in a browser, or use VS Code + Live Server.

The desktop layout is designed around the supplied 1280×1024 reference and also includes responsive breakpoints for tablet/mobile.
