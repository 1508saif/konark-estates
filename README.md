# Konark Estates — Pricing Page

## Files
- `index.html` — page structure and inline SVG icons
- `style.css` — desktop + mobile responsive styling
- `script.js` — navigation, mobile menu, enquiry modal, WhatsApp enquiry and cost-sheet download

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Functional items
1. Desktop header uses the full width:
   - Konark Estates logo/brand on the far left
   - navigation centered
   - WhatsApp + Enquire Now on the right
2. Towers is gold and underlined as the active navigation item.
3. Mobile navigation becomes a hamburger menu.
4. Pricing table remains horizontally scrollable on mobile.
5. Mobile table spacing, typography and badges are compact while desktop spacing remains unchanged.
6. Download Cost Sheet generates a CSV directly in the browser.
7. Enquire Now opens a working enquiry form and opens WhatsApp with the submitted details.
8. WhatsApp buttons open a pre-filled WhatsApp chat.
9. Floating WhatsApp button remains available on desktop and mobile.

## Important
Replace `919999999999` in `index.html` and `script.js` with the actual Konark Estates WhatsApp number before production use.
